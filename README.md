# AtoZ.FnB — هویت بصری و دارایی‌های برند

مخزن دارایی‌های برند AtoZ.FnB به‌صورت بازتولیدپذیر نگهداری می‌شود. این نسخه شامل سامانهٔ لوگو و ساختار آماده برای قالب‌های محتوا و بخش‌های وب‌سایت است. خروجی‌های لوگو از روی توکن‌های مرکزی ساخته می‌شوند و تغییر مستقیم فایل‌های خروجی توصیه نمی‌شود.

## ساختار نهایی مخزن

```text
brand/
├── tokens.json                 # منبع واحد رنگ، متن، هندسه و مشخصات خروجی
└── references/                 # مرجع‌های تصویری تأییدشده برای بازطراحی

logo/
├── index.html                  # گالری و دانلودگر دوزبانهٔ لوگوها
├── en/{svg,png}/               # لوگوهای انگلیسی در سه حالت رنگی، تک‌رنگ، سفید
├── fa/{svg,png}/               # لوگوهای فارسی در سه حالت رنگی، تک‌رنگ، سفید
├── shared/{svg,png}/           # نماد AZ مستقل
├── icons/{svg,png}/            # آیکون برنامه و فاوآیکن‌ها
└── guidelines/{svg,png}/       # راهنمای دوزبانهٔ استفاده از لوگو

content-templates/
├── social/                     # جای توسعهٔ قالب‌های شبکه‌های اجتماعی
├── carousels/                  # جای توسعهٔ قالب‌های اسلایدی/کاروسل
└── video-covers/               # جای توسعهٔ کاورهای ویدئو

website/
└── sections/                   # ساختار بخش‌های وب‌سایت؛ محتوا در فاز بعد
    ├── home/
    ├── about/
    ├── services/
    ├── resources/
    └── contact/

tools/
├── build_logo.py               # تولید SVG لوگو، آیکون و گالری HTML
├── build_guidelines.py         # تولید راهنمای لوگو از توکن‌ها
├── render_png.mjs              # تولید PNGها و اندازه‌های فاوآیکن با sharp
├── requirements.txt            # وابستگی‌های پایتون
├── package.json                # ابزار رندر Node.js
└── fonts/                      # فونت‌های OFL موردنیاز برای تبدیل نوشته به مسیر
```

## دارایی‌های فعلی

در `logo/en` و `logo/fa` چهار چیدمان وجود دارد: وردمارک تنها، افقی، عمودی و لاک‌آپ کامل؛ هرکدام با نسخه‌های `color`، `mono` و `white` و در هر دو فرمت SVG و PNG. نماد AZ بدون زبان در `logo/shared` قرار دارد. SVGهای لوگو متن زنده ندارند و نوشته‌ها به مسیر تبدیل شده‌اند. PNGهای لوگو شفاف و ۲۰۴۸ پیکسلی‌اند.

`logo/icons` شامل آیکون برنامهٔ SVG/PNG و فاوآیکن در اندازه‌های ۱۶، ۳۲، ۴۸، ۱۸۰، ۱۹۲ و ۵۱۲ پیکسل به‌همراه فایل ICO و Web Manifest است. گالری `logo/index.html` را می‌توان مستقیماً در مرورگر باز کرد و نسخه‌ها را فیلتر و دریافت کرد.

پوشه‌های `content-templates/` و `website/sections/` فعلاً ساختار مرحله‌های بعد هستند؛ دارایی‌های آن‌ها هنوز ساخته نشده‌اند. فاز جاری فقط بازنگری لوگو، آیکون و نظم فایل‌های مربوط به آن است.

## بازسازی خروجی لوگو

از ریشهٔ مخزن اجرا کنید:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r tools/requirements.txt
python tools/build_logo.py
python tools/build_guidelines.py
cd tools
npm install
npm run render-png
```

رنگ‌ها، نوشته‌ها، فرم هندسی نماد، نام فارسی، حداقل اندازه و حریم امن در `brand/tokens.json` قرار دارند. متن فارسی با HarfBuzz شکل‌دهی می‌شود تا اتصال درست حروف و ترتیب راست‌به‌چپ حفظ شود؛ خروجی لوگو به مسیر برداری تبدیل می‌شود. فونت‌های همراه شامل Vazirmatn، Montserrat و Lato با مجوز SIL Open Font License 1.1 هستند؛ جزئیات در `tools/fonts/LICENSES.txt` آمده است.

## اصلاحات این بازبینی

- فرم AZ و پیکان از مرجع تصویری اصلی دوباره ترسیم شده است؛ پیکان اکنون همان مسیر پیوسته و حرکت رو به بالا از بخش A تا نوک Z را دنبال می‌کند.
- نوشتار فارسی برند به «آ تو ز اف‌ان‌بی» اصلاح شده است.
- نمونهٔ ایمیل `info@atozfnb.info`، شمارهٔ `+98 21 0000 0000` و نشانی `Tehran, Iran` داده‌های نمونه هستند و نباید به‌عنوان اطلاعات واقعی منتشر شوند.
- محتوای قالب‌ها و صفحات وب هنوز طراحی یا تأیید نشده است و برای فازهای بعد نگه داشته شده است.

## فرض‌ها، داده‌های نمونه و موارد تأییدنشده

- عبارت فارسی برند طبق اصلاح اخیر «آ تو ز اف‌ان‌بی» است؛ دو بخش وردمارک فارسی جداگانه در توکن‌ها نگهداری می‌شوند.
- ایمیل `info@atozfnb.info`، تلفن `+98 21 0000 0000` و نشانی `Tehran, Iran` در فایل توکن‌ها دادهٔ نمونه‌اند و باید پیش از انتشار با اطلاعات واقعی جایگزین شوند.
- هندسه از مرجع اصلی بازترسیم و به مسیرهای SVG تبدیل شده است؛ تصویر مرجع به‌عنوان bitmap داخل SVG جاسازی نشده است.
- خروجی‌ها از نظر بصری و فنی (ساختار SVG، نبود متن زنده در SVG، شفافیت و اندازهٔ PNG، لینک‌های گالری و ابعاد فاوآیکن) بررسی شده‌اند. چاپ فیزیکی، آزمون خوانایی در همهٔ اندازه‌ها، بررسی حقوقی/علامت تجاری و تأیید نهایی کارفرما انجام نشده‌اند.
- نسخه‌های سفید برای زمینهٔ تیره‌اند؛ نسخه‌های color و mono برای زمینهٔ روشن طراحی شده‌اند.
