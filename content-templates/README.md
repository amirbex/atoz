# قالب‌های محتوایی — ساختار آماده

این پوشه برای قالب‌های قابل‌تکرار محتوای AtoZ.FnB است. در این مرحله فقط ساختار پوشه‌ها ثبت شده و هیچ قالب محتوایی نهایی نشده است.

- `social/` — قالب پست‌ها و استوری‌ها
- `carousels/` — قالب کاروسل و اسلایدهای آموزشی
- `video-covers/` — کاور ریلز و ویدئو

هر خروجی آینده باید از توکن‌های `../brand/tokens.json` استفاده کند و فایل منبع قابل‌ویرایش را کنار خروجی‌های PNG/SVG/HTML نگه دارد.
