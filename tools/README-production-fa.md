# یادداشت نگه‌داری بستهٔ محتوای قدیمی

`build_week1_package.py` و خروجی‌های موجود در `پیش انتشار/ماه اول/هفته اول/` میراث فاز قبلی‌اند و بخشی از خروجی جاری هویت AtoZ v3 نیستند. این ابزار را برای بازسازی یا انتشار اجرا نکنید؛ هرگونه استفاده از بستهٔ موجود نیازمند بازبینی مستقل محتوا، نام، URL/شناسه‌های شبکهٔ اجتماعی و مجوز مالک است. این نوبت هیچ خروجی محتوایی تازه‌ای از آن تولید نکرد.

## خروجی جاری هویت

- سازنده: `tools/build_brand_assets.py`
- رندر SVG به PNG و PDF: `npm --prefix tools run render-brand`
- برندبوک: `logo/brand-book/`
- لوگوها: `logo/primary/`, `logo/subbrands/`
- موشن: `logo/motion/`
- قالب‌های خالی: `content-templates/`
- ممیزی فونت: `brand/fonts/font-inventory.json`

URL و شناسهٔ شبکهٔ اجتماعی در ابزارهای محتوى میراثی به placeholder تغییر داده شده‌اند؛ برای طراحی جاری هیچ دامنه/هندل فرض نشده است.
